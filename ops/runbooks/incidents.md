# Incident Runbook

## Severity Matrix
- Sev1: direct user-fund at risk
- Sev2: settlement liveness degraded
- Sev3: indexing or UI-only issue

## First Response
1. Open incident channel and assign IC.
2. Freeze frontend writes.
3. Gather affected game/guess IDs and tx hashes.
4. Rotate roles if key compromise is suspected.
5. Publish short status update.
